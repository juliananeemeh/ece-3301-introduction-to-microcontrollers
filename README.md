## ECE 3301 - Introduction to Microcontrollers

# Overview
This repository contains lab projects for the Introduction to Microcontrollers course. The labs involve programming and testing using assembly and C.

# Hardware
- PIC18F4620 microcontroller
- Development board and other components (LEDs, seven segment display, LCD screen, Fan, light sensor, temp sensor, etc)

# Software
- MPLAB IDE
- Assembly language
- C programming language

# Repo structure
Each folder contains a specific lab assignment including:
- Lab instructions
- Source code
- Supporting files (if applicable)
